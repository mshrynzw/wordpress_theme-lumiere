# SAMPLE HAIR — LUMIÈRE テーマ デザインモックアップ

美容院サイトのデザイン確認用の静的モックアップです（HTML / CSS / JavaScript のみ）。
WordPress テーマの PHP 実装は含みません。承認後も、このファイルをそのままテーマへコピーせず、テーマの設計・実装方針に沿って作り直す前提です。

**状態: 完了（デザイン確認済み）。** このモックアップをテーマ実装時のデザイン基準として扱います。WordPress 管理画面への接続や実店舗データへの差し替えは、テーマ実装の作業範囲です。

`salon-site/index.html` をブラウザで開いてください。サーバーは不要です（ファイルを直接開いて動きます）。JavaScript を有効にしてご確認ください。

### 確認したい画面幅

ブラウザの開発者ツール（レスポンシブ表示）で、次の幅を目安に確認してください。

| 幅 | 想定 | 主な変化 |
|---|---|---|
| 375〜390px | スマートフォン（最優先） | ドロワーメニュー、画面下の固定ボタン、スタイル2列 |
| 700〜899px | タブレット | スタイル3列、スタッフ2列、予約方法3列 |

| 1100px〜 | 広いPC | ヘッダーにメニューを横並び表示、スタイル4列 |

PC表示を重点的に見ていただきたいのは、ホーム・ヘアスタイル・メニュー・料金・アクセス・予約です。

### 試せる操作

- ヘッダーのメニュー（スマートフォン）：開閉、Esc キーで閉じる
- ホームのスタイルギャラリー：横スクロール、矢印ボタン、ギャラリーにフォーカスして左右キー
- ヘアスタイル：施術メニュー・髪の長さ・おすすめでの絞り込み
- メニュー・料金、よくある質問：分類へのページ内移動、質問の開閉
- 予約：各ボタンを押すと「接続先は未設定」の案内が出ます（外部へは送信しません）
- 画面上部の「確認パネル」
  - **管理画面で編集する範囲を枠で表示**：各ページで管理画面から編集する想定の範囲を点線で示します
  - **動きを止める**：アニメーション設定（テーマ設定の候補）の確認用です。端末で動きを減らす設定が有効な場合は、最初から動きが止まります

## 2. 仮データとプレースホルダー

### 仮データ

店名・所在地・営業時間・電話番号・料金・スタッフ名・文章・予約先はすべて架空です。

- 店名は「SAMPLE HAIR（サンプル美容室）」、所在地は「〇〇県サンプル市・〇〇駅周辺」の設定です。
- 電話番号は `000-0000-0000` のダミー表記です。郵便番号も `〒000-0000` です。
- お知らせ・コラムのタイトルや本文には「（例）」「仮の文章」等を添えています。
- 全ページの上部と下部に「SAMPLE」表示を入れています。

**仮データはすべて `assets/js/sample-data.js` の1ファイルにまとめています。** 各 HTML はページの骨組み（`data-render` の枠）だけを持ち、店舗情報や本文を直接書いていません。ファイル内のコメントで、管理画面のどの編集対象にあたるかを示しています（保存方式は決めていません）。

ホームのセクションの表示・順序は `home.sections` の並び順と `visible` で切り替えられます。テーマのカスタマイズ候補の確認用です。

### プレースホルダー画像

`assets/img/placeholder/` の SVG はすべてレイアウト確認用に作成した図形で、写真ではありません。画像内に「SAMPLE｜ヘアスタイル写真」などの種類を表示しています。

| 種類 | ファイル | 比率 | 写真の形 |
|---|---|---|---|
| ヘアスタイル | `style-01〜10.svg` | 3:4 | 上がアーチ型 |
| 店内 | `interior-01〜04.svg` | 4:3 | 角丸（小） |
| スタッフ | `staff-01〜04.svg` | 4:5 | 角丸（大） |
| コラム・お知らせ | `column-*.svg` / `news-*.svg` | 16:10 | 角丸（小） |
| メイン写真の予備プレースホルダー | `hero-main.svg` | 4:5 | アーチ型 |
| 地図 | `map.svg` | 16:10 | 角丸（小） |

写真の形は種類ごとに分け、ヘアスタイル写真だけをアーチ型にして主役にしています。代替テキストは仮の写真の内容を想定して `sample-data.js` に入れています。

## 3. デザインの考え方（要点）

- 配色：アイボリー `#FBF7F0`、リネン `#F2EADD`、サンド `#DDCCB3`、ウォルナット `#6B4A33`、ココア `#3A2A20`。おすすめ表示などにだけ、くすんだ緑 `#5F6649` を差し色として使っています。`style.css` 冒頭の変数にまとめています。
- 書体：見出しにShippori Mincho、本文にZen Kaku Gothic Newを使用し、`assets/font/` にフォントファイルとOFLライセンスを配置しています。
- デザインはヘア雑誌のようなエディトリアル構成を軸にしています。トップでは縦書きの大きなコピーとアーチ型のメインビジュアルを組み合わせ、英字ラベルで誌面らしさを加えています。
- ヘアスタイルは大きな横送りギャラリーで見せ、リネン色の面には髪の流れを思わせる線を重ねています。線と背景の奥行きはスクロールに合わせて動きます。
- 予約エリアは濃いココア色の面にしてページ内の見せ場にします。動きを減らす設定では背景の移動を止めても内容・操作が成り立ちます。
- ホームのヒーローには生成したイメージ写真を3枚使用し、一定間隔のフェード切り替え、停止・再開、写真選択を実装しています。動きを減らす設定にも配慮しています。ファイルは `salon-site/assets/img/hero/` にあります。
- ヘアスタイル、スタッフ、店内、記事などその他の写真枠にはプレースホルダー図形を使っています。実店舗の写真や情報への差し替えはテーマ実装時に行います。
- 画像には幅・高さを指定し、画面外の画像は `loading="lazy"` で遅延表示します。`srcset` / `sizes` の枠組みを入れています（仮画像は1サイズのみ）。

## 4. 未決事項・要件どおりに表現できなかった点

1. **要件書との照合とデザイン確認:** Claudeの初回制作時には [`docs/requirements.md`](../docs/requirements.md) を参照できていませんでした。制作後に要件書と照合し、ページ構成、デザイン方針、管理画面での編集、予約導線、アクセシビリティ・表示速度に関する主要要件が反映されていることを確認しました。ユーザーがモックアップを完成として確認しました。
2. **仮データの読み込み:** このモックアップでは、仮データを `sample-data.js` に集約しています。JavaScript が無効だと内容は表示されず（`noscript` で案内のみ表示）、WordPress の実データ構成とは異なります。これは静的モックアップの実装上の制約で、テーマのデータ設計時に解決します。
3. 地図の表示方法（埋め込み地図・画像・リンクのみ等）は未定のため、プレースホルダー画像にしています。
4. 予約導線の実際の接続先（電話番号のリンク方式、外部予約サービス、LINE / SNS）は未定です。ボタンは案内を表示するだけにしています。
5. SNS リンク（店舗・スタッフ）は任意項目として一部のスタッフにのみ表示例を入れています。表示の有無の扱いは未定です。
6. お知らせ・コラム一覧のページ送りは表示例のみで、2ページ目はありません。分類ごとの絞り込みやアーカイブの形も未定です。
7. ヘアスタイルの詳細画面は依頼範囲にないため作っていません。カードは一覧表示のみです。
8. お知らせ・コラム詳細で存在しない `id` を指定した場合は、先頭の記事を表示しています（「見つからない」画面は未作成）。
9. 美容院の特徴（カット・カラー・接客など）は候補として掲載しており、実店舗について確認済みの内容ではありません。ページ内にもその旨を注記しています。
10. プライバシーポリシーは仮の本文で、法的な確定文ではありません。
11. 書体は端末内のフォントに依存するため、Windows・Mac・Android で見え方が変わります。見出しの書体を確定させる場合は、配布可能なフォントの同梱を検討する必要があります。
12. 「確認パネル」と「SAMPLE」表示はモックアップ専用です。テーマ本体には含めない想定です。
